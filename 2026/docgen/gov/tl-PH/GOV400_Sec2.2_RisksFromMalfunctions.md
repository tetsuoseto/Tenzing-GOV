>oldlace|black||11|15|br  ■ Kapag pumalya ang mga AI system na para sa pangkalahatang layunin, maaari silang magdulot ng pinsala. Kabilang sa mga pagkabigong ito ang pagbibigay ng maling impormasyon o impormasyong inimbento lamang (na madalas ilarawan bilang “mga halusinasyon”), pagsulat ng depektibong computer code, at pagbibigay ng mapanlinlang na medikal na payo. Posibleng magdulot ang mga pagkabigong ito ng pisikal o sikolohikal na pinsala at maglantad sa mga user at organisasyon sa pagkasira ng reputasyon, pagkalugi sa pananalapi, o pananagutang legal.
>oldlace|black||11|15|br      
>oldlace|black||11|15|br  ■ Kadalasang mahirap unawain o hulaan ang asal ng mga modelo, kaya nagiging mahirap tiyakin ang pagiging maaasahan ng mga ito. Kadalasan, hindi rin makapagbigay ng makabuluhang paliwanag tungkol sa asal ng modelo, makahula sa mga partikular na paraan ng pagkabigo, o makapagpakita na hindi mangyayari ang mga ganitong pagkabigo kahit ang mga developer ng mga AI model na para sa pangkalahatang gamit. Maaari ring magdulot ng mga pagkabigo ang mga malisyosong aktor sa pamamagitan ng pakikialam sa pagbuo ng AI o pagbibigay sa mga sistema ng mga adversarial na input na nakalulusot sa mga pananggalang.
>oldlace|black||11|15|br      
>oldlace|black||11|15|br  ■ Mas mataas ang mga panganib sa pagiging maaasahan ng mga AI agent dahil kumikilos sila nang awtonomo at maaaring direktang makaapekto sa iba pang sistema o sa pisikal na mundo. Maaaring magdulot ng mas malaking pinsala ang mga pagkabigo ng agent dahil mas kaunti ang pagkakataon ng mga tao na makialam. Nagdudulot ng higit pang panganib ang mga multi-agent system, dahil maaaring kumalat at lumala ang mga error sa pamamagitan ng mga interaksiyon ng agent.
>oldlace|black||11|15|br      
>oldlace|black||11|15|br  ■ Mula nang mailathala ang naunang Ulat (Enero 2025), sa pangkalahatan ay naging mas maaasahan ang mga sistema ng AI at, dahil dito, mas malawak na itong ginagamit sa komersyo. Sa pangkalahatan, nabawasan ang posibilidad ng maraming uri ng pagkabigo, gaya ng mga halusinasyon, ngunit karaniwan pa ring nagkakamali ang mga sistema kapag nagsasagawa ng mas masalimuot na mga gawain.
>oldlace|black||11|15|br      
>oldlace|black||11|15|br  ■ Sa kabila ng malaking pagsisikap sa pananaliksik, walang kombinasyon ng mga pamamaraan ang nakatitiyak sa mataas na pagiging maaasahan na kinakailangan sa mga kritikal na larangan. Maaaring mabawasan ng mga bagong pamamaraan ng pagsasanay at pagbibigay ng access sa mga tool sa mga AI system ang posibilidad ng mga pagkabigo, ngunit karaniwan ay hindi ganap na naaalis ang mga ito.
